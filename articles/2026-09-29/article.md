# AI挖Alpha，别再"玄学炼丹"了

## 一、那个让所有量化人失眠的瞬间

你可能也经历过：

熬了两个月写了个因子。回测曲线像爬楼梯，IC稳，夏普漂亮。你心想，成了。

然后放进模拟盘，或换个时间段、股票池再跑——曲线瞬间塌了。那根漂亮的斜线，像有人在你上车那刻把梯子抽走。

这就是量化圈极为出名的痛：**Alpha decay（因子衰减）**——不是不赚钱，而是"赚着赚着就不赚了"：有效信号被越来越多人发现、复制、交易，超额收益随之被磨平。

这两年很多人想用大模型解决它：给AI一个prompt，让它"生成因子"。结果呢？

## 二、"玄学炼丹"的真相

先说结论：**把挖因子整个丢给大模型自由发挥，大概率是一场昂贵的幻觉。**

你会发现AI很"勤奋"：吐出几十个公式，层层嵌套、参数一堆，看起来很高级。但仔细看，它其实只做两件事：

**一是复读那些极度拥挤的信号。** RSI、动量、反转……这些训练数据里最多，市场里也极度拥挤。你让AI"自由发挥"，它自然滑向那条被反复走过、早已拥挤的老路。

**二是用复杂度堆出"看起来很棒"的过拟合。** 参数越多、嵌套越深，回测越好看。这不是发现规律，是把运气翻译成了一个复杂公式。业内叫它 **p-hacking**：在噪声里反复翻找，总能找到"显著"结果，但换个时间就失效。

所以问题不是"AI笨不笨"，而是：**我们给AI立规矩了吗？**

打个比方。去奶茶店，让厨师"随便配一杯好喝的"，可能端来一杯说不清所以然的东西；给你一张菜单——茶底、糖冰、加料、冷热、杯型——你就在**有边界的空间**里做选择，配出来的大概率能喝，还能复现。

挖因子也一样。差距不在"让AI自由编"，而在"给AI一张菜单，把它关进笼子"。

## 三、第一层：可信度——用约束换稳定

2025年KDD会议上有篇工作叫 **AlphaAgent**，干的就是"给大模型立规矩"。

它不是"一问一答"，而是拆成三人小队，轮流上岗：

**Idea Agent 提假设 → Factor Agent 翻译成可执行的表达式 → Eval Agent 回测校验 → 再反馈修正。** 一圈一圈闭环。

更关键的是它立的三条**正则化约束**：

1. **原创性约束**：防止AI复读那些极度拥挤的信号，逼它去找别人没用的。
2. **复杂度约束**：防止它无脑堆参数，把过拟合压住。
3. **假设一致性约束**：尤其狠的一条——AI写的"因子描述"和"数学表达式"必须对得上。

前两条靠工程就能做，第三条才是真正的"反人性"——它要求AI**说人话，还要说到做到**。

技术上，它把因子表达式解析成一棵 **AST（抽象语法树）**，相当于把公式"拆成骨架"，能量化它多复杂、和Alpha101、Alpha158多像。太像，是在抄；太复杂，是在赌。

论文给了一组数据（注意，**这是论文回测结果，不是实盘收益**）：

- 中证500：年化超额 **11.00%**，IR **1.488**，最大回撤约 **-9.36%**
- 标普500：年化超额 **8.74%**，IR约 **1.05**

消融实验更有意思：加上因子建模约束后，命中率从 **0.16 升到 0.29**；符号化组装让开发成功率从 **0.75 升到 0.83**。

先别激动。**这些数字不能照搬**：股票池、费用、调仓频率都会让收益大幅变化。它真正说明的不是"照着抄就能赚"，而是——**约束，比自由更值钱。**

另一篇 **AlphaSchema** 从另一角度印证：它把"要搜什么"和"怎么实现"解耦，先在**结构化的交易语义空间**里找逻辑——事件、环境、约束、方向、输出五个维度，就是那张奶茶菜单——再交给大模型翻成代码。

它有个很妙的结论：**不同大模型的实现成功率差很多，但只要实现成功，因子质量差别很小。** 也就是说，**因子好不好，主要看你的研究计划清不清晰，而不是用没用更贵的模型**——可信度不一定靠烧钱，也能靠**流程设计**补上。

![可信度的三根支柱：原创性 / 复杂度 / 假设一致性——用约束把大模型「关进笼子」，换回稳定与可复现](imgs/01-constraints.webp)

## 四、第二层：可证伪——别让AI"编故事"

光有约束还不够。大模型有个天生的毛病：**太会迎合你。**

有个真实案例：让模型做各公司市场份额的图表，做得像模像样。仔细一看——所有份额**全都一样**。

追问为什么，模型答：**"因为我没有数据，所以把它们设成了一样。"**

所以有句金句流传很广：**"AI告诉你一件新颖、意外、可能用于交易的事时，你也该把怀疑提到很高的等级。"**

放进因子研究，"可证伪"就是**假设一致性**——因子的**描述、数学表达式、经济逻辑**必须对得上：说是"捕捉反转"，表达式却是趋势项？不行；说是"流动性溢价"，算出来却是纯技术指标？也不行。

能说清、能对上、能被检验，才叫可证伪。

![可证伪：因子的「描述 · 数学表达式 · 经济逻辑」三者必须对得上——让 AI 说的话经得起怀疑](imgs/02-falsifiable.webp)

## 五、第三层：经济含义——相关性不等于因果

到这一步你可能想：有约束又能解释，够了吧？还不够。真正的高手会问更狠的问题：**这个因子为什么会赚钱？**

以Marcos López de Prado为代表的观点讲得很透——**因果风险，比过拟合风险更值得警惕。** 有文章把它整理成四层：

1. **统计有效**：IC、RankIC、夏普都稳，过了严谨检验。但这只说明"过去有预测力"。
2. **经济解释**：市场为什么会长期付这笔钱？风险补偿、流动性溢价，还是行为偏差？
3. **因果识别**：不是证明A和B相关，而是尽量证明**A导致了B**——用自然实验、双重差分、因果森林逼出因果。
4. **微观结构验证**："订单簿失衡"为何有Alpha？背后有库存管理、信息交易、做市报价支撑。

极好的反面教材：**BTC和某只AI概念股同步上涨，IC和夏普都很漂亮。** 但真正的驱动变量可能是**"流动性"**——是它同时推高了这两者。**BTC不是原因，只是共同结果。** 流动性一变，因子立刻失效。

所以判断一个因子值不值得信，最后落到三个拷问：

> **为什么会赚钱？谁在持续支付这笔钱？什么情况下它会失效？**

答不上来，它多半是个"故事会"选手——回测里岁月静好，实盘里原形毕露。

> **人话版小结**：两样东西一起涨，不代表其中一个推着另一个涨——很可能只是有第三只手（比如"流动性"）同时推动了它们。所以别只盯着"过去准不准"，要问清楚：**它到底在赚谁的钱？这笔钱为什么愿意持续付？什么时候会不付？**这三问答不上来，再漂亮的回测也只是个好听的故事。

![判断一个因子值不值得信：统计有效 → 经济解释 → 因果识别 → 微观结构验证，四层逐级抬高门槛](imgs/03-causal-layers.webp)

## 六、AI是研究助手，不是印钞机

把三层串起来看，有件很有意思的事：**这轮AI挖因子的进步，涨点几乎都不在"模型更强"，而在"系统更清楚"。**

- **可信度**，靠DSL、AST、语义空间这些**结构化约束**，把大模型关进笼子；
- **可证伪**，靠**假设一致性**，逼AI说的和做的一致，经得起怀疑；
- **经济含义**，靠**因果识别**，追问它为什么赚钱、谁在付费、何时失效。

三层叠起来，才是从"玄学炼丹"到"可验证系统"的真正跃迁。所以有句话值得贴在电脑前：**不该追求更会"编公式"的模型，而该追求更会"组织研究流程"的系统。** 更进一步——**LLM不该替代量化研究框架，而该嵌入量化研究框架。**

AI能帮你更快提假设、更快试错，是个好助手，但不是印钞机。把印钞的期待放上去，失望的只会是你自己。
